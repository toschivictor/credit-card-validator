# Credit Card Validation

This project is a credit card validation application. It has a frontend and a backend application.

## Frontend

The frontend is a React application that allows users to validate credit cards.
For more information, please refer to the [client README](client/README.md).

## Backend

The backend is a Node.js application that provides a RESTful API for credit card validation.
For more information, please refer to the [server README](server/README.md).
